# Sample call-center data

`call_center_calls.csv` contains 800 synthetic inbound calls from a fictional call center. It includes answered and abandoned calls, wait durations, handle durations, agent IDs, and first-contact resolution status.

- Source: https://databasesample.com/datasets/call-centre-dataset-calls-agents-queues-and-abandonment
- Direct file: https://database-sample-website.s3.eu-north-1.amazonaws.com/datasets/call-centre-dataset-calls-agents-queues-and-abandonment/v1/csv/calls.csv
- Dataset version: 1
- License: CC0 1.0 Public Domain
- Published SHA-256: `aa80c8f88f3c2b7ec66e5b2eb440be5733447cb49ad4021da7b0baffdf9f71fd`

The default demo analyzes `handle_seconds`. Abandoned calls have no handle time and are therefore reported as blank exclusions. The data is synthetic and contains no real customers.
